WakeWay Privacy Policy

WakeWay uses location during an active journey to detect when you are approaching your chosen destination and trigger an alert.

Local-first design

The core journey tracker stores the active journey on the device. The app is designed to keep the destination alarm working when network access is unavailable.

Optional cloud features

Login, family sharing, chat, AI, weather, railway information and optional sync use external services only when configured/enabled.

Location sharing

Family location sharing must be explicitly enabled. It should be treated as temporary journey sharing and can be stopped by the user.

Data deletion

Provide in-app controls to delete saved places and journey history. A production release must document the exact server retention periods and deletion process.

Third parties

Depending on configuration, WakeWay may use Supabase, Cloudflare, Google Gemini, Open-Meteo, railway data services and an OSM-derived mapping provider. Check the release configuration for the exact providers used.
